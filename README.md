# 🌦️ Weather App

A simple and responsive Weather Application built using **HTML, CSS, and JavaScript** that fetches real-time weather data using the **OpenWeatherMap API**. Users can search for any city and get live weather details instantly.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature display (°C)
- 💧 Humidity information
- 🌬️ Wind speed details
- 🌤️ Dynamic weather icons based on current conditions
- ⌨️ Press "Enter" or click search button to fetch weather
- ⚠️ Basic error handling for invalid city names

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **API:** OpenWeatherMap API  
- **Tools:** Fetch API, DOM Manipulation

---

## 📸 How It Works

1. User enters a city name in the search box
2. JavaScript fetches weather data from OpenWeatherMap API
3. Data is parsed and displayed dynamically on the UI
4. Weather icon updates based on current weather conditions
